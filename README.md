# Smart Automated Electricity Bill and Energy Advisor

## Project Overview
Smart Automated Electricity Bill and Energy Advisor is a Python-based project that calculates electricity bills using a three-tier pricing system and provides personalized energy-saving recommendations.

## Features
- Takes previous and current electricity meter readings.
- Calculates electricity units consumed.
- Calculates bills using three pricing slabs.
- Classifies consumers as Low, Moderate, or High.
- Provides energy conservation advice.
- Compares current consumption with the previous bill.
- Saves billing history in a CSV file.
- Displays previously generated bills.
- Handles invalid user inputs.

## Electricity Pricing
- First 100 units: ₹5 per unit
- Next 200 units: ₹7 per unit
- Above 300 units: ₹10 per unit

## Technologies Used
- Python
- CSV Module
- OS Module
- Datetime Module

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python main.py
```
